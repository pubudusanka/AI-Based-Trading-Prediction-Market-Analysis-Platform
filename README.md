# AI-Based Trading Prediction & Market Analysis Platform

A research-oriented, production-style platform that collects market data, generates technical/market features, trains machine-learning models, produces probabilistic trading signals, evaluates them through rigorous backtesting, and displays real-time analysis via a modern interactive dashboard.

## Architecture Overview

- **Data Ingestion & Signal Engine:** Java 21+, Spring Boot, Spring Data JPA, REST/WebSocket APIs
- **Feature Pipeline & ML Engine:** Python (Pandas, NumPy, Scikit-learn, XGBoost, PyTorch)
- **Database & Cache:** PostgreSQL (TimescaleDB friendly), Redis
- **Dashboard UI:** Next.js / React with TypeScript
- **Containerization:** Docker & Docker Compose
